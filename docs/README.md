# docs/ — ray

Esta pasta é o **estado atual** do projeto: o que alguém que clonasse o repo
amanhã precisaria ler para entender o sistema como ele é hoje. Exploração e
trabalho em aberto não moram aqui.

## Os arquivos

| Arquivo | Muda com que frequência | Quem lê |
|---|---|---|
| `CLAUDE.md` (raiz) | Quase nunca — só em decisão de arquitetura | A IA, em todo turno |
| `architecture.md` | Quando a estrutura, os módulos ou as fronteiras mudam | Quem chega no projeto |
| `conventions.md` | Quando uma convenção de código ou de trabalho muda | Quem vai contribuir |
| `features.md` | Quando uma feature muda, com o porquê das decisões dela | Quem vai mexer na feature |

## Mantendo em dia

`architecture.md`, `conventions.md` e `features.md` descrevem estado, não
intenção. Se um deles ficar defasado do código, ele virou ficção — corrija junto
com a mudança que o defasou.
